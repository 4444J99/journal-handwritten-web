Payload fields

Listening feedback: sampleId, decision (unreviewed, keep, revise, reject), notes, renderDigest, pronunciationDigest, bankDigest. Each digest is sha256 followed by a colon and 64 hexadecimal characters.

Pronunciation: entries containing lineId, token, and the supplied pronunciation. Realization: the existing realization document under realization. Source fingerprints are taken from the selected version.

Reader lifecycle preview

The preview stays disabled until invoked. Notes are projected through their existing clearance checks. Media starts only after a separate user action. Preview placement remains undecided.

Optional audio, regions, and realization objects each require url and source: {pieceId, versionId, sourceFingerprint}. When a saved record is selected, each also requires its exact revisionId. Asset URLs must use this origin. Audio and image sha256 values are verified before attachment. Digest-bound realization packages remain unavailable here.

Regions also require sourceAnchor: {status, box}. A valid box enables a labeled full source image; this panel does not apply a crop.
