# T09 pilot interface — 2026-11-05 review baseline

The Python pilot is local and private. It makes no network requests. Fixture audio is generated tones and noise, never the author's voice. No reader or studio integration is activated by this pilot.

## Commands

```sh
python3 audio_build/render.py packet --out /absolute/new/packet
python3 audio_build/render.py fixture --out /absolute/new/fixture-session
python3 audio_build/render.py run --manifest /absolute/fixture-session/session.json --out /absolute/new/listening
python3 audio_build/render.py validate --manifest /absolute/fixture-session/session.json --report /absolute/new-validation.json
python3 audio_build/render.py init-session --config /absolute/session-request.json --out /absolute/new/human-session
```

Every output directory must be new. `run` produces `receipt.json`, `samples/*.wav`, `timing/*.json`, and `SHA256SUMS`. It never copies raw takes to the listening directory. Pilot validation/processing errors return a nonzero exit code; `run` writes `diagnostic.json` and `validate` writes its requested report. Input-file errors also appear as JSON on stderr, while command-line syntax errors print usage. The prompter consumes `recording/packet/prompts.json` or the `prompts.json` generated by `packet`.

`validate` checks input format, identity, reviewed boundaries, source text and requested unit coverage. `run` additionally checks mode-specific processing parameters and output budgets before writing successful samples. A structural validation result alone is not a successful render or a listening decision.

## Listening receipt

```json
{"schema_version":1,"fixture":true,"session_id":"t09-fixture-v1","manifest_sha256":"SHA256","samples":[{"id":"forward","label":"Forward concatenation — synthetic calibration fixture","path":"samples/forward.wav","sha256":"SHA256","duration_seconds":1.0,"mode":"forward","fixture":true,"source_refs":[],"parameters":{},"timing_path":"timing/forward.json","timing_sha256":"SHA256"}],"warnings":[],"errors":[],"privacy":{"master":"private","rendered_release":"undecided","harness":"local-only"},"reproducibility":{}}
```

Sample paths are relative to the receipt. Generated sample `source_refs` contains source IDs, hashes and reviewed frame intervals; specification references include repository paths. Raw-file filesystem paths are not added automatically. Operator-supplied source metadata is preserved, so review it before sharing a receipt; the server does not redact it. Every sample explicitly identifies fixture status. The manifest's artistic decisions remain unresolved; implementation parameters are labeled technical calibration defaults. Do not infer publication permission from a playable sample.

## Prompt data

`recording/packet/prompts.json` is an object with `schema_version`, `packet_id`, `fixture` (false: prompts themselves are not audio), `status`, `session_minutes`, `recording_request`, `author_decisions`, and a `prompts` array. Each prompt has `id`, `section`, `label`, `instruction`, `target`, `take_number`, `estimated_seconds`, and `requires_decisions`. There are exactly 50 numbered prompts: 2 calibration, 24 short concatenation, and 24 texture prompts (12 categories, two takes each). These are technical calibration instructions, not poems or author captions. A prompter may show all prompts for preparation, but must flag unresolved required decisions before recording.

`author_decisions` accepts either a direct map keyed by `D01`–`D14` or a list of records with an `id`. A resolved record requires nonblank strings in `choice` (alias `value`), `author` (alias `authority`) and `source` (alias `source_ref`). It does not inherit top-level attribution from a wrapper. Pre-record requirements are D01, D02, D03 and D10; later artistic/release choices may remain null. The exact decision list/map must match in the prompter packet and intake configuration. [The recording runbook](../recording/README.md) includes a projection helper that preserves the blank packet and updates the new packet hash.

`init-session` requires `packet_path` (relative to the configuration or absolute), an actual packet SHA in `source_refs`, and matching `author_decisions`. It captures the packet bytes under `acquisition/prompts.json`; each selected prompt has a source-bound snapshot. Reviewed alignment JSON must include `wav_sha256`, `wav_frames`, `sample_rate`, `take_id`, `reviewed: true`, a nonblank `reviewer`, and contiguous supported-phone intervals with integer frame boundaries. Use `labels-template` or `import-textgrid`, then review the actual source; no forced alignment is implied.

## No live playback acceptance

The local listening harness may demonstrate explicit start/stop and cancellation. Reader playback remains gated on an author listening decision. Physical iPhone silent-switch behavior is an untested author decision and device test, not a promised browser behavior.
