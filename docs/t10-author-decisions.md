# T10 author choices: minimum input for one real pilot

**Status: pending author input.** English/Latin `p001` / `p001-diary1-0` is a technical fixture, not your selected study language, final poem version, or approved public release. Greek-first and multi-script font expansion remain suggestions from the October 28 research.

The smallest useful next input is **one line you write**, with its language/script and method identified, attached to one existing source version. The complete 22-line fixture has already tested storage, provenance, font use, and exclusion; a full translated poem or full new alphabet is unnecessary for the next private engineering check.

| Decision/input | Concrete proposal or bounded choices | Implementation consequence |
|---|---|---|
| Source poem/version | Retain candidate `p001` / `p001-diary1-0`, or name one other existing version. | Pins the exact source reading and line IDs. Choosing another editorial version creates a separate realization. This does not choose a public poem. |
| First language and script | Existing English/Latin only, or your named target. Greek is the prior research suggestion, still unaccepted. If Greek, specify language/orthographic tradition rather than assuming modern monotonic or ancient/polytonic. | The language tag, script code, direction, repertoire, marks, and shaping tests follow your actual choice. A script name alone does not establish the language. |
| Operation | Translation, transliteration, or visual/script realization. Supply your own line and the source-line association. | Stores a distinct mode and realizer credit. No tool converts the English into another language or chooses spellings for you. |
| Glyph input | Existing handwriting font for the current Latin fixture; for a new script, draw only the sequences used in your supplied line, three samples each, plus any context/mark forms needed for that script. | Generate a small exact worksheet from your line. Import labeled, bounded crops; inspect them before any tracing or font compilation. |
| Glyph/source evidence | State whether it is a fresh handwritten capture, an existing scan, or an existing-font derivative. Retain original photo/scan, date if known, author credit, locator, and SHA-256. | The importer preserves bytes, crop coordinates, and labels. It does not infer authorship, letter identities, archival-master status, or creative quality. |
| Review/fallback | Decide whether a visible fallback specimen is useful while glyphs are pending; review actual shaping and line breaks. | Whole-run fallback stays labeled as fallback. It is never promoted to author handwriting. A new script requires its own browser/script acceptance pass. |
| Visibility | Keep the pilot private while inputs are being reviewed. | Reserve/withheld sources and assets stay excluded. Public release requires T03 clearance of exact new text/assets/exports and separate execution authority. |
| Submission target | Name the journal, prize, or grant **and cycle** if you want one pursued. | The research's named programs remain examples. Current eligibility/deadline evidence is documented; no application or inquiry is sent. |
