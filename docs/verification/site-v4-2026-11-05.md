## How the verifier works

- Serves `site/` on 127.0.0.1 (random port), GET/HEAD only, MIME by extension, no directory listing (directories give 404),
  requests resolving outside `site/` (including by symlink) are refused.
- Matrix: {desktop 1280x900 dsf 1; mobile 390x844 dsf 3, `mobile=true`, touch emulation 5 points} x {light, dark}, set with
  `Emulation.setDeviceMetricsOverride` and `Emulation.setEmulatedMedia` (`prefers-color-scheme`).
- Dark assertion: `matchMedia('(prefers-color-scheme: dark)').matches` must equal the cell's expectation.
- Waits for `body.ready` (30 s timeout, failure if missed).
- Records: console `error` and `warning`, `Runtime.exceptionThrown`, `Log.entryAdded` level error, `Network.loadingFailed`,
  responses with status >= 400. Browser-initiated `/favicon.ico` 404s (the page has no icon link) are listed under "ignored" and not counted.
- Interaction uses `Input.dispatchMouseEvent`, `dispatchTouchEvent` (mobile) and `dispatchKeyEvent`. The page's own `window.__jc`
  test hooks are used only to locate a tappable item (`tallest`, `centerOn`, `zoom`, `quad`), to read state, and, in the mobile cells,
  to show the bar (`ui(true)`) because the fine-pointer rest path does not apply there. Taps, Escape and button clicks are real input events.
- Exit status is non-zero on console error, exception, Log error, failed request, HTTP >= 400, failed dark assertion, missing
  `body.ready`, or an exercised check that fails. Warnings are recorded, not failing.

### Method caveats found during the run

- A first run reported the desktop auto-hide as 1.62 s after the pointer left. Cause: the verifier moved the pointer to the bar,
  waited, then left without ever entering the revealed bar, so the page's 2.8 s timer (started at reveal) was already running. The
  verifier now moves the pointer into the revealed bar before leaving; the page behaviour was not changed. The same first run
  counted the favicon 404 as a Log error; it is now classified as ignored.
- Items measured with test hooks (item location, bar display on mobile) depend on `window.__jc` existing in `site/index.html`.
- "Tap outside" and Escape check `focusKey()` returning null after 1.5 s; they do not inspect pixels.
