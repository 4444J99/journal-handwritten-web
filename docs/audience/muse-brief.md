# Optional Meta Muse operating brief — inactive

**Specification:** `T06-MUSE-01` · **Mode now:** disabled · **Adoption decision:** D12, unresolved · **Cost ceiling:** $0 · **Source lineage:** #59–#61 and the existing November 3 SOP. See [current verification](platform-policy.md) before relying on any product feature.

Interest in Muse is recorded; adoption is not. This specification prepares a technical boundary for a later author-selected trial. It creates no account, connector, memory entry, reminder, task, notification, scheduled post or permission grant. The old #59 scheduled-agent proposal is superseded.

## Smallest useful mode

The manual workflow works without Muse. Even a manually supplied Muse trial requires verification that no disallowed automatic account connections are present; manual inputs alone do not isolate accounts. If the author chooses a trial, start with **manually supplied, non-identifying aggregate metrics and technical metadata only**. Connected-account mode is optional and unavailable until effective scope can be verified. Do not assume a conversational instruction can make a write-capable connector read-only or exclude other accounts.

| Input allowed for a selected trial | Purpose |
|---|---|
| Public release number or an opaque operational ID; format label; actual post and observation times | Align records and observation windows without giving the poem text to the tool. |
| Native metric labels and aggregate counts provided by the author; explicit missing-value reasons | Arithmetic and factual tables only. No copying reader identities or messages. |
| Dimensions/file type/frame count provided from T07's cleared export manifest | Technical format checks; no image upload or regeneration. |
| The author's already selected hashtag list, if the author chooses to provide it | Count entries and flag exact duplicates. Do not generate replacement hashtags or caption wording. |
| Adopted thresholds and this checklist | Apply the stated arithmetic and report missing inputs, without inferring poem quality. |

**Excluded inputs:** poems, scans, audio, drafts, Reserve titles/lists, private-page lists, draft captions/notes, bios, project descriptions, comments/DM text, reader names/contact details, private source repositories, email, storage drives, contacts, and personal/ETCETER4 account data. A public URL is a record locator, not permission for the tool to browse its artistic contents.

## Allowed outputs and prohibited actions

Allowed outputs are a table of supplied numbers, reproducible arithmetic, technical missing-field/format checks, a list of documented confounders and a proposed logistics step for the author to consider. A low-reach flag says that distribution was low under a chosen rule. It must not assess a poem, rewrite work, interpret reader sentiment or promise better reach.

No posting, scheduling, sharing, commenting, replying, messaging, liking, following, deleting, archiving, account editing, purchases, subscriptions or settings changes. No generated public creative or interpretive copy, no generated imagery and no access to private work. Do not automatically adopt a suggestion or create a recurring task.

## Preconditions for any adoption

1. Author selects D12 and supplies the exact Meta product/app and account region. Distinguish the consumer agent from Muse Spark/model announcements and unrelated products with the same name. Current access and price must be checked; any new paid requirement ends the trial proposal under no-spend.
2. Record D01/D02 account boundaries. A dedicated project-only Accounts Center is an option, not evidence of full Meta-system separation. Verify that no disallowed automatic Facebook/Instagram/Threads connections exist before even a manual-input trial. If the needed separation cannot be verified, leave Muse off and use the weekly record without it. This check does not authorize moving or disconnecting accounts.
3. Read the current terms/privacy controls and capture the actual control names, date and scope. Do not apply an old UI path or the historical January 20, 2027 claim without verification. Interaction-training controls do not establish the treatment of public Instagram posts.
4. Inspect effective connector scopes and default actions with no new grant. Require a verified no-write boundary for connected mode. Current guidance documents “Always ask” and “Allow once”; account availability and operation remain untested. An “Always ask” setting is an additional safeguard; it is not a read-only OAuth scope. If the connector necessarily supplies artwork, messages or other profiles, it does not meet this brief.
5. Use a plainly labelled numerical fixture with no real poem, account or reader data. Compare arithmetic independently and verify that unknown inputs remain unknown. This is a later trial acceptance step, **not a test performed in T06**.
6. Author approves a narrowly scoped trial. Record functions, input list, effective permissions and stop conditions. Reminders/scheduled tasks remain out of scope until separately selected and authorized; they are not needed for this SOP.

## Technical instruction block for a later manual trial

This is technical operating text, not public copy:

> Work only with the aggregate numbers and technical metadata I provide for vers.forms. Do not access accounts, external pages, messages or files. Do not create tasks or reminders. Do not post, schedule, share, edit, delete, reply, message, follow, purchase or change settings. Do not write or suggest public wording, hashtags, poems, captions, alt text, bios or project descriptions. Do not create or alter images. Preserve missing values as missing. Keep reach, views and event counts separate. Calculate only the specified event-rate formula when every input exists and reach is positive. Report counts, exact windows, technical errors and confounders. Do not judge the poems or infer reader sentiment. Any proposed next step remains a proposal for me to decide.

Do not paste this block into a tool during T06. If a selected tool cannot reliably follow the boundary, stop using it rather than expanding the permitted data.

## Stop and review

A request for private content, broad account access, a paid upgrade, public-copy generation or an external action ends the trial. Keep a private technical incident receipt and obtain the author's instructions for any revocation or correction. Disconnection, deletion or “forget” features must be described according to their current documented limits; none is evidence that past processing or model influence has been reversed.

**Acceptance status:** specification prepared; product/account-specific configuration, permission enforcement, connector functionality, arithmetic trial and ongoing operation are all untested here. No claims of active protection or automation are made.
