## Evidence classes

- **Author decision:** directly requested in this T06 task or attributed to the author by a cited repository exchange/session record. Repository records are identified as records; the original Claude conversations have not been independently retrieved here.
- **Derived default:** a documented implementation choice inferred under prior delegation, still labelled as derived. Examples: as-posted numbering, participation around the 100 and candidate `p001`.
- **Proposal:** a recommendation in historical research or this packet. A recommended option is not adopted.
- **Observed implementation:** read from a specified source revision or observed endpoint. This is narrower than author approval or successful operation.
- **Unresolved / inaccessible:** a decision is absent or the required source/control evidence was not accessible. Absence from search does not prove nonexistence.
